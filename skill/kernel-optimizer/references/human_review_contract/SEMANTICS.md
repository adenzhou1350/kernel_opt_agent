# 统一语义

## 时间与因果

- **实测耗时**：生产实现或明确命名的对照实现的 GPU kernel-active
  统计量。必须同时写单位、统计量、计时方法和工作负载。
- **对照耗时**：只改变一个预注册因素，其余生产条件保持不变的实测
  耗时。
- **关键路径贡献**：`生产耗时 - 对照耗时`。它表示删除目标工作后从
  实测关键路径上消失的时间，不等于目标工作的独占执行时间。
- **重叠隐藏**：目标工作确实存在，但删除后实测耗时没有显著下降，
  说明它被并行工作掩盖。报告统一使用“重叠隐藏”，不用 masked、covered、
  隐蔽或其它近义词。
- **交互影响**：A、B 分别删除与同时删除时的非加和部分。对延迟差值
  `dA=Tfull-TnoA`、`dB=Tfull-TnoB`、`dAB=Tfull-TnoAB`，统一报告
  `dA+dB-dAB`，并说明正负号所采用的含义。
- **同切分基础耗时**：保留生产 CTA/warp 切分、搬运、同步、数值边界和
  可观察写回，只移除被研究计算后的实测耗时。它只描述当前切分，不是
  理论下界，也不是硬件下界。
- **尚未解释的关键路径**：现有匹配证据无法闭合的生产耗时。必须同时
  给出待补实验，不允许用猜测比例填充。

## 上界、工作点与下界

- **硬件规格峰值**：厂商文档在特定条件下给出的架构上界，只用于背景。
- **匹配饱和点**：使用与生产相同的指令/访问模式、布局、warp/CTA 组织、
  寄存器和 shared 约束、grid、cache 层级及依赖形态，经参数扫描得到的
  最佳稳定服务率。
- **生产工作点**：生产切分在同一匹配曲线上的实际请求规模、并行度和
  服务率。
- **理论下界**：只有强制工作量、匹配硬件服务率、DAG 依赖和资源
  可组合性全部建立后才能使用。否则必须写“理论下界尚未建立”。
- **可行调度下界**：在已校准资源图上满足依赖、容量、所有权和同步约束
  的最短预测时间。它比单资源 max 更严格，但仍受模型边界约束。

## 资源与并行度

- **单 CTA 资源占用**：静态寄存器、shared memory、线程和 warp 数。
  只回答驻留上限，不回答运行时利用率。
- **全卡并行覆盖**：当前 grid 相对 SM 数或可驻留槽位的覆盖。不得命名为
  SM 利用率。
- **活跃 SM 内效率**：已经获得工作 CTA 的 SM 内，目标服务率相对匹配
  饱和点的比例。
- **计算器件占空比**：目标计算器件在有效窗口中可发射目标指令的时间
  比例；没有动态计数或可验证代理时标为尚未测量。

内存层级必须分别命名为 **HBM**、**L2 请求服务**、**TMA 请求服务**、
**shared memory** 或 **LDSM/STSM**。不得把它们统称为“显存带宽”。
字节量必须区分：

- **唯一数据量**：算法上不重复的有效数据。
- **实际请求量**：按线程/CTA 和重复读取统计的请求字节。
- **L2 字节量**：有计数器或等价证据识别的 L2 边界流量。
- **HBM 字节量**：有计数器、隔离缓存或等价证据识别的 HBM 流量。
- **shared 字节量**：shared/LDSM/STSM 边界的读写量。

## 证据与决策

人类报告只使用四种证据状态：

- **生产匹配**：生产 ABI、工作量、几何、布局、分配、cache、同步和计时
  语义均匹配。
- **条件匹配**：已明确列出不匹配项，结论只在这些边界内成立。
- **仅供方向判断**：历史几何、代理负载或静态分析只能说明方向。
- **尚未测量**：缺少能支持该问题的合格测量。

决策状态与证据状态分开，只允许：**保留**、**否决**、**待验证**。

主页面不得出现内部 benchmark ID、文件哈希或绝对路径。实验使用人类
可读名称，例如“去掉预测矩阵乘”“仅保留数据搬运与同步”“分别运行
A、B 及 A+B”。内部 ID、路径和哈希只能放在折叠的开发者附录。
