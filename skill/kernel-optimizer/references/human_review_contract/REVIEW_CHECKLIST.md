# 发布前审核清单

## 数据与模型

- [ ] 工作负载、硬件、软件栈、计时方法和统计量已冻结。
- [ ] 阶段实测时间来自同一生产 session；若不是，页面明确区分。
- [ ] 工作量区分有效/padding、唯一/请求、L2/HBM/shared 边界。
- [ ] 首次服务延迟与稳态吞吐由不同读数支持。
- [ ] 生产工作点与匹配饱和点共享机制、单位和适用边界。
- [ ] 每个“无法打满”原因都有对应单因素扫描。
- [ ] 单资源曲线进入 DAG 前完成 A/B/AB 可组合性检查。
- [ ] 当前调度预测、最佳可行预测与生产实测给出残差。
- [ ] 未闭合项集中列出，理论下界缺证时明确写尚未建立。

## Microbenchmark

- [ ] 每项实验含问题、保持不变、唯一改变、结果、含义、边界。
- [ ] 计时、DCE、正确性、cache、clock、竞争负载和 kernel count 已控制。
- [ ] 最终 SASS 证实目标机制，或报告明确降级。
- [ ] 关键结论由交错配对和独立进程复验支持。
- [ ] 原始样本和源/二进制身份可从开发者附录追溯。

## 页面

- [ ] 首屏十秒内可读出总时间、最慢阶段、主限制和证据缺口。
- [ ] 阶段宽度与实测耗时成比例。
- [ ] 容量、运行时服务率和设备覆盖没有混成“利用率”。
- [ ] 主页面不含内部 benchmark ID、绝对路径或哈希。
- [ ] 证据状态只用四种词，决策状态只用三种词。
- [ ] 一图一单位，关键信息不依赖 hover，红色只表示否决。
- [ ] 开发者附录默认折叠。

任何未勾选项都必须在报告的“缺失证据”中产生可执行下一步，不能静默
发布。
