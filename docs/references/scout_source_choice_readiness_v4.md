transparent backend-generated metadata. A filename-only rule selects the whole
original test module: target-stem affinity after stripping leading underscores,
then sorted top-level `test_*.py`; if no match, first sorted top-level module.

## First paired comparison

This initial slot compares two acquisition policies using the same approved
GLM-5.3 configuration and unchanged published Mini default-agent loop/parser:

1. Rule + GLM: read the target and selected companion in deterministic contiguous
   UTF-8 chunks of at most24KiB, spending at most four source actions, then run
   the whole original selected module once. Unavailable suffixes remain explicit.
   One GLM review may submit a finding, no finding or incomplete work; no further
   exploration or semantic repair is granted to this arm.
2. GLM direct: choose source/native observations under the same common ceilings.
   The same evidence and final native submission requirements apply.

Run rule first, then direct; record this unrandomized order limitation. Freeze
both predictions before owner adjudication. The rule's lower realized use is
recorded, not padded with waste to appear equal. Each arm has at most8 queries,
8 actions,360 decision seconds,80s/request,30s/native command,4,096 output
tokens/query and98,304 prepared-message bytes/query. Final native submission
must be nonempty and state FINDING/NO_FINDING/INCOMPLETE plus evidence/witness
paths and actual uncertainty. Presence or shell exit0 is not correctness.

Stop an arm at60,000 inclusive reported tokens and this pair at120,000, retaining
post-response overshoot. Unknown usage or ambiguous provider/native execution
stops new calls pending inspection of the same handle/history. No model retries,
provider fallback, answer repair, successful rerun or slot substitution. Use the
existing pre-request native-action guard; reaching its limit is incomplete, not
a forced no-finding result. Keep source/test hashes and raw observations intact.

These are maximum ceilings, not equal realized compute or known monetary cost.
Cached input is included in total input; no unknown provider price or unmeasured
owner time becomes zero. All failed preparation, model and adjudication work is
